# Job Description

## Role : GCP DevSecOps Engineer

## Key Responsibilities
- Automate security scans, data extraction, and reporting using scripting (PowerShell/Python)
- Manage and secure cloud environments (GCP/AWS/Azure) and container platforms (Kubernetes/Docker)
- Integrate security tools via APIs and CI/CD pipelines
- Analyze scan outputs, troubleshoot issues, and ensure data accuracy
- Build and maintain inventory, reports, and dashboards for security insights
- Support governance, compliance, and security standards (RBAC, encryption, SSL/TLS)
- Collaborate with teams and vendors for implementation and issue resolution
