# Role: DevSecOps Engineer

## About the role

We are looking for a **DevSecOps Engineer** having **4+ years of experience** to build and run secure, automated delivery pipelines across a multi-cloud environment. You will own CI/CD, Kubernetes deployments, and cloud infrastructure across AWS and Azure, while embedding security into every stage of the delivery process rather than treating it as a final check.

This role suits someone who is equally comfortable writing pipelines, operating Kubernetes clusters, and improving application security posture.

## What you will do

- Design, build, and maintain CI/CD pipelines in GitHub Actions, including build, test, deployment, rollback stages, and approval gates.
- Deploy and operate applications on Kubernetes (AWS EKS and Azure AKS), including Helm charts, manifests, autoscaling, upgrades, and cluster troubleshooting.
- Configure and manage Application Gateway and ingress/routing, including TLS, WAF, and API Gateway setups.
- Embed application security into CI/CD pipelines using:
  - SAST
  - SCA/Dependency Scanning
  - Container Image Scanning
  - Secret Scanning
  - Quality Gates to block risky changes
- Manage secrets and configuration across environments using AWS Secrets Manager or Azure Key Vault with rotation and least-privilege access.
- Collaborate with development teams to remediate vulnerabilities, improve secure coding practices, and reduce security findings reaching production.
- Set up monitoring, alerting, and basic SLOs to measure pipeline and release health.
- Support incident response and perform root-cause analysis for pipeline and platform issues.

## Required Skills

- 4+ years of hands-on DevSecOps experience.
- Strong production experience with both AWS and Azure.
- Strong experience building CI/CD pipelines using GitHub Actions (self-hosted runners are a plus).
- Practical Kubernetes experience deploying and operating workloads on AWS EKS and/or Azure AKS using Helm and Kubernetes manifests.
- Experience configuring Application Gateway, Load Balancers, Ingress Controllers, TLS, and WAF.
- Hands-on experience integrating security into CI/CD pipelines, including:
  - SAST
  - SCA/Dependency Scanning
  - DAST
  - Container Image Security
- Good understanding of Application Security (AppSec), OWASP Top 10, and Secure SDLC.
- Scripting experience with Bash, PowerShell, or Python.
- Comfortable working with Git-based workflows.

## Good to Have

- Relevant certifications such as:
  - AWS Certified Solutions Architect
  - AWS Security Specialty
  - Microsoft Azure Architect
  - Microsoft Azure Security
  - CKA / CKAD
  - Any recognized cybersecurity certification
- Experience with:
  - AWS Secrets Manager
  - Azure Key Vault

  - Microsoft Defender for Cloud
  - Amazon GuardDuty

- Exposure to observability tools such as Grafana, Prometheus, and Azure Monitor.
